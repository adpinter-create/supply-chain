# Supply chain tools

Three planning tools for andreipinter.com, published to GitHub Pages and refreshed by a daily GitHub Action (same setup as PulseNews). All data is synthetic sample data.

| Page | What refreshes |
|---|---|
| `supply-planner/` Supply & demand planner | "Plan as of" moves to today. Each month that passes becomes history, and a new plan month is added at the end. Booked orders, customer forecast, supply and stock keep the same proportion to the plan, so exceptions and months of cover stay realistic. |
| `capacity/` Capacity & cost model | The 15-month horizon rolls to start at the current month. |
| `scheduler/` Production scheduler | Static for now. The page is generated by the scheduling engine (`schedule.py` + `tools/roll_forward.py`), which is not in this repo yet. Once added, the workflow can run it daily. |

The scripts check every morning and only change something when a new month has started, so most runs commit nothing.

## Setup

1. Settings → Pages → Source: **GitHub Actions**.
2. Settings → Pages → Custom domain: `supplychain.andreipinter.com`.
3. DNS (Squarespace → Domains → DNS): CNAME, host `supplychain`, data `adpinter-create.github.io`.
4. Actions → Refresh supply chain tools → Run workflow.
5. When the domain verifies, tick **Enforce HTTPS**.

Pages: `https://supplychain.andreipinter.com/` (index), `/supply-planner/`, `/capacity/`, `/scheduler/`.

## Testing a roll locally

```
python scripts/roll_supply.py 2027-01     # roll the supply planner to a given month
python scripts/roll_capacity.py 2027-01
python -m http.server                     # then open localhost:8000
```
Use a scratch copy: the scripts rewrite the pages in place.
